# Day1 SQL Learning Journey



## What is SQL?

SQL stands for **Structured Query Language**. It is used to perform operations on relational databases such as retrieving data, filtering data, sorting results. 
SQL is one of the most important skills for roles like Data Engineer.

## Why I Learned SQL

I learned SQL because it is a fundamental skill for working with data. It helps in understanding how data is stored, connected, filtered, and analyzed inside relational databases. 
SQL is also considered one of the first important skills required to become a Data Engineer.

## Topics I Learned

### 1. Relational Databases
I learned that SQL is mainly used with relational databases. In relational databases, data is stored in tables made up of rows and columns.

### 2. Primary Key and Foreign Key
I studied two important database keys:

- **Primary Key**: A column or set of columns that uniquely identifies each row in a table.
- **Foreign Key**: A column that creates a relationship between two tables by referring to the primary key of another table.

These keys are important for maintaining data integrity and connecting related tables.

### 3. Writing Basic Queries
I learned how to write basic SQL queries using:

```sql
SELECT column_name
FROM table_name
WHERE condition;
```

- `SELECT` is used to choose columns.
- `FROM` is used to specify the table.
- `WHERE` is used to filter rows based on a condition.

### 4. Additional Query Clauses
After learning basic queries, I studied more SQL clauses:

- `ORDER BY` – used to sort results in ascending or descending order.
- `DISTINCT` – used to remove duplicate values from the result.
- `LIMIT` – used to restrict the number of rows returned.

These clauses make query results more useful and organized.

### 5. Practice
I practiced writing multiple example queries to improve my understanding of filtering, sorting, and selecting data from tables.

### 6. Aggregate Functions
I also learned aggregate functions, which are used to summarize data:

- `COUNT()` – counts rows
- `SUM()` – adds total values
- `AVG()` – finds average value
- `MIN()` – finds minimum value
- `MAX()` – finds maximum value

These functions are very useful for analysis and reporting.


## What I Gained

By learning SQL, I understood:

- how to work with relational databases
- how to write basic and structured queries
- how to filter and sort data
- how to remove duplicate values
- how to limit query results
- how to use aggregate functions for data analysis
